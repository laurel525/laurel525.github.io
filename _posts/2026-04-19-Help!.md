
# Help, I Need Somebody!

Laurel Barrett

## Assignment Description 

This program utilizes a switch, the Arduino buzzer, and the use of functions to spell out a person's name in morse code when the circuit is open and SOS when the circuit is closed. The use of multiple functions -- a function for each dot, dash, space, and letter -- make debugging and replicating easier!
