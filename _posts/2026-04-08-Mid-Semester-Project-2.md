
# Simultaneous Sparklies!

Laurel Barrett

## Assignment Description 

After writing three separate state-based programs to mimic flash patterns of three fireflies -- Flash Bulb, Big Dipper, and Synchronous -- this final part of the project combines the three separate programs to allow the flash patterns to occur simultaneously on different pins within the Arduino. This project incorporated programming skills learned thus far and implemented a state-based approach using one delay to allow numerous separate programs to run at once.

#### Tip for Someone Approaching this Project...

I would urge someone combining the three separate programs to be mindful of their brackets! At first, I accidentally included too many, separating the different loops too much. Removing my extraneous brackets made the code appear cleaner.
