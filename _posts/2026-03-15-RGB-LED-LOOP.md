
# RGB LED Loop Project!

Laurel Barrett


## Assignment Description 

The goal of this assigment is to apply the programming we created in the last assignment to print different LED colors to an actual LED. Using the Arduino, the program will be altered to light up a red, green, and blue LED every 10th time through the loop. The light should remain on for 0.5 seconds and each color should shine three times in a row.
