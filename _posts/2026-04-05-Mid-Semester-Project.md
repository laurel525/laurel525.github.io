
# Separate Sparklies!

Laurel Barrett

## Assignment Description 

This project involves creating three separate state-based Arduino programs that mimic three different firefly patterns: Flash Bulb, Big Dipper, and Synchronous. The goal of the project is to test the programming skills learned thus far in the semester. In thinking carefully about these programs in a state-based manner (before and during the execution of them), we can better understand how to achieve different effects on the Arduino that will be helful down the line in other projects, and ultimately put all three programs together to work in one unit for the next part of the mid-semester assignment.
