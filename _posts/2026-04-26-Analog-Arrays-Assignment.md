# Analog Arrays!

Laurel Barrett

## Assignment Description 

This program utilizes the concept of arrays (a pwm and a bool array) to house LED pin values and their on/off state. The program utilizes random seed to randomly pick a number that corresponds to a PWM pin and its respective bool state. Then, for the pin randomly chosen, it is randomly lit up at a random brightness. This loop repeats every 1 second with LEDs being turned off if they are chosen when already on.
