# ASCII Art!

Since it's the start of the 30th season of the women's pro league, I thought I would program some basketball-related ASCII Art! I found the design on the website, ASCII Art Archive by an anonymous programmer. I found the model under the basketball section of the archive.

Website: https://www.asciiart.eu/sports-and-outdoors/basketball

Below is an image of the output of my code. It's a basketball player shooting a mid-range jump shot. 

![Basketball ASCII Art](https://laurel525.github.io/assets/img/basketball.jpg)

## Code Snippet

```c

 int main(){
    printf("        ___|\n");
    printf("     0  \\%%/|~~\\\n");
    printf(" 0//            |\n");
    printf(" 8              |\n");
    printf("/ >             |\n");
    printf("~ ~           ~~~~~");
    
 ```

### Program's Purpose

Through the use of printf statements, various keyboard symbols, and spacing techniques, I was able to replicate the basketball ASCII Art that I found on the Archive website! It was super simple, and lots of fun to see it come to life so quickly. The main tricky part was figuring out the spacing, but once I did it was smooth sailing.
